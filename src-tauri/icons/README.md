# How to update

## App icon

1. Update `app.svg`
2. Export `app.png` (1024x1024px, 32bit, with transparency)
3. From `src-tauri` run `cargo tauri icon ./icons/app.png`
4. Do a clean build

The `android/` and `ios/` folders are produced by that command but nothing in
this desktop app reads them.

## Tray glyphs

`tray/` holds hand-made monochrome glyphs that `src/tray.rs` embeds with
`include_image!`. They are not generated by `cargo tauri icon`.

- `tray-black-*.png`: pure black on transparent, used as a macOS template image
  (44 px is the 2x menu bar size)
- `tray-white-*.png`: used on Windows and Linux
- `tray-active-*.png`, `tray-disconnected-*.png`: state variants, not wired up yet

The SVG sources for these live outside the repo with the logo master files.
